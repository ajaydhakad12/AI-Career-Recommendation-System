# AI Career Recommendation System

## 📌 Overview
This project is an AI-based Career Recommendation System built using **Python** and **Machine Learning**.  
It predicts suitable career paths for students and professionals based on their skills and interests.

## ⚙️ Features
- Data preprocessing and feature encoding
- RandomForest model training and evaluation
- Skill-level based career prediction
- Streamlit interface for easy deployment

## 🛠️ Installation
Clone the repository and install dependencies:
```bash
git clone https://github.com/ajaydhakad12/AI-Career-Recommendation-System.git
cd AI-Career-Recommendation-System
pip install -r requirements.txt


🚀 Usage
Run the Streamlit app:

bash
streamlit run app.py
